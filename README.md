# 妙法莲华经 · 全经诵读

《妙法莲华经》（姚秦 鸠摩罗什 译）全部 28 品及前后序的朗读，经文与语音逐句同步。

**在线收听：** https://linruitan.github.io/lotus-sutra-audio/

- 正在朗读的句子会高亮，页面随之滚动
- 点击任意一句，就从那一句开始听
- 语速 0.5×–2×，可单句循环、连续播放下一品
- 记住上次听到的位置

## 关于朗读

语音由开源模型 [Fun-CosyVoice3](https://github.com/FunAudioLLM/CosyVoice) 在本地合成。生僻字、多音字按佛经传统读法逐一校对过（例如 阿耨多罗三藐三菩提 nòu、阿僧祇 qí、摩侯罗伽 jiā，以及「乐」按字义分读 lè / yuè），并用三个语音识别模型交叉复核，漏读和读音错误已逐句修正。

如果听到读错的地方，欢迎在 Issues 里指出品名和大致时间。

# 读音词典：local_tts.py 运行时会自动加载同目录下的这个文件。只影响发音，不改原文。
#
# 每行一条「原词=读法」，长词优先匹配，这里的条目会覆盖脚本内置条目。读法有三种写法：
#   1. 拼音：佛=fo2 、偏袒=pian1 tan3（声调 1–4，多字用空格隔开）
#      CosyVoice 会把它转成发音标记，最准确。但少数拼音不在 CosyVoice 的发音表里
#      （例如 juan4、tui2、yuan2），或者实际读出来不对（例如 yue4 会被读成 jué），
#      运行时会提示「不支持」，这时改用第 2 种写法。
#   2. 同音字：闇=暗 、伎乐=伎月（用读音相同、模型不会读错的常用字代替）
#   3. 正则：re:正则=替换，例如 re:(?<=[种诸是])乘=剩
# 行尾可以加「  # 说明」。改完词典后，删掉受影响章节的 mp3 重新运行，
# 或者用 patch_sentences.py 只重做受影响的句子。
#
